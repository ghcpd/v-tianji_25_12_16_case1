## 📎 Key source files (high-level)
- **App.tsx** — top-level app wiring conversation list, message thread, search bar, contact list, and message input. Uses in-memory `mockConversations` and `currentUser`.
- **data.ts** — mock data: `currentUser`, `users`, `mockConversations`.
- **types.ts** — `Message`, `Conversation`, `User` types; used only for typing (imported as `type` to avoid runtime import issues).
- **`src/components/*`** includes:
  - `ConversationList` — list with active highlight, last message preview, and selection handler
  - `MessageList` — render messages with sender names and message content
  - `ChatInput` — input form to send messages
  - `SearchBar` — filter input
  - `ContactList` — simple contact list excluding current user
- **Tests** — Unit tests in `src/__tests__` using Vitest + React Testing Library (test files: ConversationList, MessageList, ChatInput, SearchBar).
